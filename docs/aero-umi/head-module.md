# Head module

Optional egocentric capture module for Aero UMI.

## Specifications

| Specification | Value |
|---|---|
| Main cameras | Global-shutter stereo RGB ×5 |
| Depth sensing | ToF ×1, 640 × 480 |
| Illumination | Active infrared |
| Field of view | 208° horizontal · 193° vertical |
| Head pose | 6-DoF (VIO + IMU) |
| Time sync | < 1 ms |
| Hand tracking (bare hand) | 21 keypoints, MPJPE ≤ 10 mm |
| Weight | 240 g |
| Continuous capture | 8 h |
