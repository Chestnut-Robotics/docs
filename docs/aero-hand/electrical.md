# Electrical and communication

Power, wiring and the CAN FD bus.

## Power

| Specification | Value |
|---|---|
| Operating voltage | 20–50 VDC wide input |
| Continuous stall current | 6 A at 24 VDC |
| Standby power | < 7.2 W |
| Power connector | XT30-M |

## Communication

| Specification | Value |
|---|---|
| Bus | CAN FD |
| Connector | A1257H-CJT |
| Low-level current loop | 10 kHz |
| High-level communication | 200 Hz |
| Host adapter | CAN FD to USB converter board, included |

Tactile data has its own CAN FD port. See [Tactile interface](tactile.md).
