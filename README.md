# Chestnut Developer Docs

Built with MkDocs Material.

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/mkdocs serve -a 127.0.0.1:8001
```

Pages live in `docs/`, navigation in `mkdocs.yml`.

Pushing to `main` deploys to https://chestnut-robotics.github.io/docs/ via GitHub Actions.
